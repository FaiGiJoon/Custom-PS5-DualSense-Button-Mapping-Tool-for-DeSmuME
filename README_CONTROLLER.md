# DeSmuME PS5 DualSense Setup Guide

This project provides a tool to help you set up your PS5 DualSense controller with the DeSmuME DS emulator.

## Prerequisites
- PS5 DualSense controller connected to your PC (via Bluetooth or USB).
- DeSmuME emulator installed.

## Using the Configuration Tool
1. Run the provided Python script to generate the configuration:
   ```bash
   python3 dualsense_to_desmume.py
   ```
2. The script will output a `[Joypad]` configuration section.

## How to Apply Settings
1. **Close DeSmuME** if it is currently running.
2. Locate your `desmume.ini` file. This is typically found in the same directory as the `desmume.exe` file.
3. Open `desmume.ini` with a text editor like Notepad.
4. Search for the `[Joypad]` section.
5. Replace the existing `[Joypad]` section with the text generated by the script.
6. Save the file.
7. Open DeSmuME and test your controller.

## Default Button Mapping
- **Circle**: DS A Button
- **Cross**: DS B Button
- **Triangle**: DS X Button
- **Square**: DS Y Button
- **L1**: DS L Button
- **R1**: DS R Button
- **Options**: Start
- **Create/Share**: Select
- **D-Pad**: Up/Down/Left/Right
- **L2**: Lid (Close/Open)
- **R2**: Boost (Fast Forward)

## Troubleshooting
If the buttons do not respond as expected:
- Ensure Windows recognizes the controller as the primary joystick.
- If you have multiple controllers connected, the ID (e.g., `0x4000`) might need to be adjusted (e.g., to `0x8000` for the second controller).
- You can always use the `Config > Control Config` menu in DeSmuME to manually re-bind if the preset doesn't match your system's HID mapping.
